# minecraft-medic-mod

Empower, heal and boost you and your allies in combat.

## Features
### Syringes
Inyect a boost. Can be used on yourself or an ally.

#### Healing Syringe
Heal 2 hearts.

#### Strange syringe
Are you sure you want to try this on?

## Upcoming ideas
### Atomizer beacons
Temporary beacons that can be placed on the ground. They atomize a certain boost in an area.

### Custom enchantments
Enchantments hat empower your medic abilities.
